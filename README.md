# Chat Interface 💬

A modern real-time messaging web application inspired by WhatsApp and Messenger. Users can send and receive text messages, share photos, and record voice messages through a clean and responsive interface.

---

## 🚀 Features

- 💬 Real-time chat interface
- 🖼️ Send and preview images
- 🎤 Record and send voice messages
- 😊 Emoji support
- 📱 Responsive design for desktop and mobile
- 🌙 Modern UI inspired by WhatsApp
- 📂 Organized code using HTML, CSS, and JavaScript

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)
